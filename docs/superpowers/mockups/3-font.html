The traditional, beautiful Urdu script. Gorgeous to read — but words cascade diagonally and need tall lines, so per-word click targets overlap and the cut/highlight backgrounds look messier. Better for reading than precise editing.

My take: Naskh for the editor (clickability + legibility), and I can offer Nastaliq as an optional "reading" font in Settings if you want the beauty when you're just reviewing. Both bundle with the app so it looks identical on every machine.
